# isecensa-bi-assets

Imagens públicas usadas nos dashboards TOTVS BI / GoodData da ISECENSA (widgets *Web content*).
Somente assets estáticos — nenhum código ou credencial.

## Como usar

No dashboard: **Add → Widget → Web content** e cole a URL:

```
https://cdn.jsdelivr.net/gh/bwasistemas/isecensa-bi-assets@main/<pasta>/<arquivo>.svg
```
